# 🛰 Mission Control

A live project board inside Claude Code: where the project stands, what Claude needs from you,
the build queue, what Claude is doing right now, recent wins and ideas. Claude keeps it current
through its `board` tool; the board is saved to `.claude/mission.json`.

## Install

```
/plugin install mission-control --marketplace pendragonzzz/rotmg-companion
```

Answer `y` to add the marketplace, then pick a scope.

## Use

- `/mission` shows the board (as a docked pane where the surface supports it, inline otherwise)
- `/mission theme`, or `t` in the pane, cycles Arcade → Ember → Frost → follow your theme
- `r` in the pane refreshes
